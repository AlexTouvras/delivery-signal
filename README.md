# Delivery Signal

A weekly delivery brief from a Jira, Azure DevOps, or other work-item export. The page says what changed, which work needs attention, and which decision is waiting. Every material claim cites a field.

Install it from the [page in this repo](https://htmlpreview.github.io/?https://github.com/AlexTouvras/delivery-signal/blob/main/docs/index.html): Apps, a one-liner, npm, or the checkout. In your own terminal, from [`delivery-signal/`](delivery-signal/), `run` opens the configuration page. A connected Jira or Azure DevOps project is fetched. A single CSV is still `run` plus the file when there is no live connection.

Details are in [`delivery-signal/README.md`](delivery-signal/README.md).
