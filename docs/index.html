Product

The Monday pack, from the export.

A weekly brief from a Jira, Azure DevOps, or CSV export. It says what changed, which work needs attention, and which decision is waiting. Every material claim cites a field. The same inputs produce the same result id.

No account. The export stays on this device. It is not sent to GitHub or written back to the project tool. Send the HTML file.

Quick Start

All install options

install

Phone. Open this page in the browser, then add it to the Home Screen. On an iPhone that is Share, then Add to Home Screen. On Android, choose Install or Add to Home screen. Open the icon and choose the CSV. Android can also share a CSV into Delivery Signal.

Computer. Install the page from the button or the browser menu. Chrome and Edge can then open a CSV with Delivery Signal. Choosing the file below works either way.

# Puts the command on this machine.
$ curl -fsSL https://raw.githubusercontent.com/AlexTouvras/delivery-signal/main/delivery-signal/install.sh | bash
# Puts the command on this machine.
$ powershell -c "irm https://raw.githubusercontent.com/AlexTouvras/delivery-signal/main/delivery-signal/install.ps1 | iex"
# For a machine that already has Node and Python.
$ npm install -g github:AlexTouvras/delivery-signal
$ delivery-signal
# The checkout is the product.
$ git clone https://github.com/AlexTouvras/delivery-signal.git
$ cd delivery-signal/delivery-signal
$ ./run
# The checkout is the product.
$ git clone https://github.com/AlexTouvras/delivery-signal.git
$ cd delivery-signal\delivery-signal
$ run

Works on macOS, Linux, and Windows. The one-liner puts the command on this machine and uses Python when Python is already there. Run the same command again to update.

How to export

  • Jira: search work items, choose Export, then CSV. Keep Issue key, Summary, Status, Updated, and Due date.
  • Azure DevOps: open the query, add columns, then Export to CSV. Keep ID, Title, Work Item Type, State, and Changed Date.
  • A renamed header goes in columns.json beside the export.
From a terminal in this repo 
python3 delivery-signal/pipeline.py issues.csv --name "Northwind" --as-of 2026-10-10 --previous issues-last-week.csv
